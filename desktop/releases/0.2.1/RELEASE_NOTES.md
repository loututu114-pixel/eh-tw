- macOS 安裝包：`universal.dmg`、`universal-mac.zip`
- Windows 安裝包：`x64-setup.exe`、`ia32-setup.exe`

- 自動更新與校驗資訊：`desktop-update.json`、`LATEST.json`、`artifacts.json`、`SHA256SUMS.txt`

## 建議下載方式

- macOS：優先使用 `universal.dmg`。
- Windows 10/11 64 位元：優先使用 `x64-setup.exe`。
- Windows 32 位元：僅在真正的 32 位元系統上使用 `ia32-setup.exe`。
- `portable.exe` 適合免安裝使用、外接硬碟或快速測試。

## 常見問題

- 想正常安裝：使用對應平台的 `setup.exe` 或 `dmg`。
- 想免安裝：使用 `portable.exe`。
- 想驗證檔案完整性：比對 `SHA256SUMS.txt`。
