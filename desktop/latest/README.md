## 版本選擇

- macOS：優先使用 `universal.dmg`。
- Windows 10/11 64 位元：優先使用 `x64-setup.exe`。
- Windows 32 位元：只在真正的 32 位元系統上使用 `ia32-setup.exe`。
- 若不想安裝，可使用 `portable.exe` 版本。

## 功能介紹

- 桌面端以漫畫閱讀為核心，提供畫冊流、資料頁與閱讀頁三段式體驗。
- 提供正常安裝版與免安裝版，方便一般使用與測試分流。
- 支援更新描述檔與校驗資訊公開發佈，方便後續升級。

## 系統建議

- macOS：建議直接使用 `universal` 安裝包。
- Windows：一般 64 位元系統請優先使用 `x64` 版本。
- 若只是臨時使用或不想安裝，可直接使用 `portable.exe`。

## 更新與校驗

- `desktop/latest/SHA256SUMS.txt`：公開校驗值。
- `desktop/latest/desktop-update.json`：桌面端更新描述檔。
- `desktop/latest/LATEST.json`：供簡單更新流程讀取的最新版本描述。
