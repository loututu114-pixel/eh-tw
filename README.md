# EhViewer Desktop 發佈中心

本頁以繁體中文為主，並附上簡短 English summary。

## 下載入口

- 最新桌面版發佈：
  `https://github.com/loututu114-pixel/eh-tw/releases/latest`
- 桌面版安裝與使用說明：
  `desktop/README.md`

## 推薦下載

| 平台 | 建議檔案 | 說明 |
| --- | --- | --- |
| macOS | `universal.dmg` | 一般安裝首選，適合大多數 Mac |
| Windows 10/11 64 位元 | `x64-setup.exe` | 一般安裝首選 |
| Windows 32 位元 | `ia32-setup.exe` | 僅在 32 位元系統上使用 |
| 免安裝需求 | `portable.exe` | 測試、隨身碟、免安裝使用 |

## 平台選擇

- macOS：優先使用 `universal.dmg`。
- Windows 10/11 64 位元：優先使用 `x64-setup.exe`。
- Windows 32 位元：只在真正的 32 位元系統上使用 `ia32-setup.exe`。
- 若不想安裝，可使用 `portable.exe` 版本。

## 功能介紹

- 提供桌面端漫畫瀏覽、資料頁、閱讀頁與下載安裝流程。
- 提供安裝版與免安裝版，方便一般使用與快速測試。
- 公開發佈檔、版本化說明、更新描述檔與校驗資訊都集中在這個 repo。
- 目前公開說明語言以繁體中文為主，方便台灣與繁中使用者直接閱讀。

## 系統建議

- macOS：建議直接下載 `universal` 版本。
- Windows：若是一般新電腦，幾乎都應下載 `x64` 版本。
- 若只想先試跑，不想安裝，可直接使用 `portable.exe`。

## 更新與校驗

- 最新更新描述檔：`desktop/latest/desktop-update.json`
- 最新校驗檔：`desktop/latest/SHA256SUMS.txt`
- 版本化說明：`desktop/releases/<version>/RELEASE_NOTES.md`
