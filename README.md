# EhViewer Desktop Releases

Public installers and updater metadata are published in this repository.

## Download

- Latest desktop release:
  `https://github.com/loututu114-pixel/eh-tw/releases/latest`
- Desktop instructions:
  `desktop/README.md`

## Package Guide

- macOS: use the `universal.dmg` installer for normal installation.
- Windows x64: use `x64-setup.exe` for normal installation.
- Windows ia32: use `ia32-setup.exe` only on 32-bit Windows.
- Portable builds are available if you do not want a normal installer.

## Metadata

- Latest updater payload: `desktop/latest/desktop-update.json`
- Latest checksums: `desktop/latest/SHA256SUMS.txt`
- Versioned notes: `desktop/releases/<version>/RELEASE_NOTES.md`

This repository is the public distribution channel. The private build repository publishes signed desktop metadata and release assets here automatically.
